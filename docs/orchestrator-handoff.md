### 🔴 설계가 바뀐 두 지점 — 둘 다 사용자 지적이 옳았다

**⑴ 자동 경로에서 상용 모델을 뺐다** (*"프로 요금제인 나는 못버틸껄?"*)

상용 백엔드는 API 가 아니라 **CLI 에이전트 호출**(`layer2_verify.call_claude_why` →
`[exe, "-p", prompt]`). 매번 새 세션이라 호출 하나마다 지침이 통째로 실린다:

    ~/CLAUDE.md 32,848 + ax-cluster/CLAUDE.md 25,048 + MEMORY.md 4,802 = 62,698자
    리뷰 프롬프트 본문 4,700자  →  **자동 로드가 본문의 13배**

[주의] **설계 초기에 내가 적은 *"3주 46K 토큰, 무의미하게 작다"* 는 틀렸다** — 프롬프트
본문만 셌다. 지적이 없었으면 요금제를 태우는 설계를 그대로 만들었다.

**⑵ 표(파서 계약)도 자동 생성하지 않는다** — 로컬이 대신 만들 수 있는지 재봤다
(`gemma4:e4b` × 실제 커밋 3건, 2026-09-19):

    형식      🔴 3/3 format_ok=True — 스키마 강제로 2026-08-17 의 벽은 풀린다
    칸 밀림   🔴 3건 중 2건 — 「위반 내용」에 `INFO` · 「항목」에 커밋 설명문
    오염      `>+</text{…` 깨진 토큰이 셀에 박혔다
    과생성    정답 7→13행(1.9x) · 2→10행(5.0x) · 1→6행(6.0x)

🔴 **`format_ok()` 통과는 「쓸 수 있다」가 아니다** — 절 + 표 헤더 둘만 본다.
NS 리뷰 20건 중 **12건이 지적 0건**이라, 그 12건에서 6행씩이면 유령 항목 70여 개
(= 진짜 지적 17건의 4배)가 `R25-3` 번호를 받아 `ax-fix` 검토 대상이 된다.
