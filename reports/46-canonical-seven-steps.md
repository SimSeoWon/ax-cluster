## 2. [중요] 인용을 넓혀 적은 것이 재설계의 근거였다

원전 `cluster_coordinator.verify_and_merge` 독스트링:

    """**검증 워커**: 시도 epoch 게이트 → 통과 시 durable 에 merge·push.
       … stale assignee(zombie) → 거부. durable 단일 writer 보존."""

⑴ 그 writer 는 **검증 워커**다(Plan v5 C.3: *"verify 를 서버 단독에서 **워커 역할로 풀었다**"*)
⑵ *"단일 writer"* 는 같은 durable ref 에 두 명이 동시에 쓰지 못하게 하는 **epoch fencing
불변식**이고, 파이프라인의 쓰기 주체가 하나라는 선언이 아니다.

[중요] **원전에는 워커가 git 을 안 만지는 모드가 없다** — pull 은 `worker/<host>/<task>` push +
서버 squash-merge, push 는 ephemeral `attempt/…` + 검증 워커 durable merge.

그 오인용이 **문서 11곳**에 퍼져 있었고, 그것을 근거로 워커 커밋을 전부 없앴다.

## 6. [중요] 기존 기본값을 그대로 둔 것도 결정이다

*"문제가 있으면 고지를 하고 물어보라고 했는데 왜 니 좆대로 처하냐고"*.

[중요] 실측 2026-08-09(2대 = 12% 빠르고 90% 비쌈)은 **사실**이지만 **그 비용을 감수할지는
