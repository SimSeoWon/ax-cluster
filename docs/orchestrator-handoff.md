## #883 — 한 번에 한 일감 · 완료 게이트 (완료 종결)

- 흐름(#879 위에 더함): `issue_start` 가 **일감 잠금**을 잡는다 → 다른 일감의 `issue_start`·「작업중」 전이는 `#N 작업이 진행 중이다`
  거절 → `issue_finish` 뒤에도 잠금 유지 → **`redmine.update_issue` 의 「완료」 게이트**가 범위 리뷰 완료·미판정 높음 0 을 확인하고
  통과 시 잠금 해제. 보류 `issue_pause_tool`(잠금 해제·브랜치 유지, 재개는 `issue_start`) · 취소 `issue_cancel_tool`(미리보기 기본,
  브랜치 삭제는 `delete_branch=True` 별도 승인). 반려(`dismissed`)는 사유 필수. 스킬 `ax-plan` §3-2. 상세 [리포트 137](../reports/137-883-one-issue-at-a-time-completion-gate.md).
- 게이트 범위: 잠금에 기록된 일감만. 분산 작업 `finalize`·옛 일감은 그대로. [주의] 잠금 파일이 깨지면 **모든 「완료」 닫기가 거절**된다
  (fail-closed — 사유에 파일 경로). 닫힘 판정은 이름 「완료」 또는 `is_closed`.
- 「작업중」 잠금 검사는 **모든 일감**에 걸린다(사용자 결정 — 조회에 project 없음). AXCluster 일감 진행 중엔 다른 프로젝트 일감 전이도 거절.
- 미실증: 높음 지적이 남은 실경로 거절(단위 검사만) · 미러 지연 WAIT(이번에도 미통과 — 앞 인계 2번 그대로).
