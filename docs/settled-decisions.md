# 확정 사항 — 다시 논의하지 말 것

여기 있는 것은 **근거와 함께 닫힌 결정**이다. 새 실측이 반박하지 않는 한 다시 꺼내지 않는다.
반박이 나오면 여기를 고치고 해당 § 문서도 같이 고칠 것 — 한쪽만 고치면 갈라진다.

## 전제 (2026-08-07 확정)

AgentTest 는 **팀** 인프라였다 — 팀원 각자의 윈도우 PC 가 자기 로컬 LLM 을 돌렸다.
이 클러스터는 **한 사람이 자기 장비를 모은 것**이다. BC-250 이 물려받은 것은 *추론 연산*이고,
AgentTest 복잡도의 상당 부분은 *팀* 때문에 생긴 것이라 이식이 아니라 **삭감** 대상이다
(§2.0, §5.2-D).

🔴 **단, "팀 때문인가?"는 틀린 질문이다.** 옳은 질문은 ***"여러 주체가 동시에 건드리는가?"*** 다.
윈도우 UE5 PC **2대가 같은 프로젝트**를 작업한다 — 같은 저장소, 같은 `task/<id>` 브랜치,
같은 큐를 친다. 그래서 **claim/lease/fencing 은 팀 군더더기가 아니라 정확성 요구사항**이다.
실측으로 확인됨: 두 번째 워커는 점유된 태스크를 가져가지 못하고, 낡은 epoch 의 제출은 거부된다 (§9.5.3).

## §4–§6 에서 닫힌 것

- **마스터 오케스트레이터는 Python** — 재작성이 아니라 이식이므로
- **추론 요청은 마스터 브로커가** — 오케스트레이션과 브로커링은 다른 층이다. 오케스트레이터는 여럿, 브로커는 하나
- **모델 배정** — 코드 생성 `qwen2.5-coder:14b` / 컨텍스트 조리 `35B-A3B IQ2_M`
- **하트비트는 스트리밍 청크 간격** — 별도 통신 인프라를 만들지 않는다
- **마스터는 폴링이 아니라 Gitea 이벤트 구동** (§5.4)
- **BC-250 은 추론 전용** — 파일을 소유하는 하네스는 윈도우에 남는다 (§2.1, §2.3)

## 2026-08-08 에 닫힌 것

- **systemd + venv, Docker Compose 아님** (마스터 서비스 한정). 워크로드가 호스트 git · SSH 키 ·
  `agy`/`claude` CLI 의 홈 디렉토리 인증 · Gitea 훅에 묶여 있다 (§5.4.4).
  `process_lifecycle.py` 는 **이식이 아니라 폐기** — `Restart=always` 가 대체한다 (`kill -9` 로 검증).
- **`gjc` 는 윈도우에서 돌고, 마스터는 그 모델 백엔드일 뿐이다.** SDK 웹소켓이 loopback 전용이고
  `--mode rpc/bridge` 가 제거돼 "마스터가 원격 조종" 은 불가능하다 (§9.1). 마스터는 `gjc` 가 부르는
  Ollama 엔드포인트 3종(`/api/chat`·`/api/tags`·`/api/show`)만 제공한다.
  따라서 `bun`/`node` 는 **윈도우** 선결 조건이지 마스터의 것이 아니다.
- **층2 검증은 fail-closed** (§9.4.4). AgentTest 의 `syntax_check` 는 의도적으로 fail-open 이었다
  (`checked=False` → 호출자가 통과로 취급). 이식본은 그것을 뒤집는다. 판정은 **마지막 비어 있지 않은 줄**에
  정확히 `VERDICT: APPROVE` 또는 `VERDICT: REQUEST_CHANGES` 여야 한다 — 없거나·형식이 틀리거나·
  타임아웃이거나·백엔드가 없으면 **차단**.
- **`qwen2.5-coder:14b` 는 구조화된 `tool_calls` 를 못 낸다** (`temperature:0` 에서 3/3 실패, JSON 이
  `content` 로 샌다). `/api/show` 가 `capabilities:['tools']` 라고 광고하는데도 그렇고, `gjc` 에는
  텍스트 폴백이 없다. 네 관문을 다 통과하는 것은 `35B-A3B` 뿐이지만 그 모델은 코드 생성 시 API 를
  환각한다. **로컬 모델을 전제로 에이전틱 실행기를 설계하지 말 것** (§9.4).

## 용어 — 🔴 `worker` 는 세 가지를 뜻한다

| 어디의 `worker` | 실제 의미 |
|---|---|
| 이 저장소의 `worker/` | BC-250 **추론 노드** |
| AgentTest 의 `worker/` | 윈도우 PC 에서 도는 **작업자 하네스** — 파일을 소유하므로 **거기 남는다** |
| 이 저장소가 그 층을 부르는 이름 | `client/` |

항상 디렉토리로 구분할 것 (§4.1).

> ⚠️ 이 파일의 이전 판은 AgentTest 의 `worker/` 가 `master/` 로 "이식된다" 고 적고 있었다.
> **틀렸다.** 2026-08-07 에 §2.1 이 정정했다 — BC-250 이 넘겨받은 것은 *추론 연산*이지 파일 작업이 아니다.
> 하네스는 윈도우를 떠나지 않는다.
