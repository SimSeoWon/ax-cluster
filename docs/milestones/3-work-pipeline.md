## 🔴 성격 — 마일스톤 2 와 무엇이 다른가

마일스톤 2 는 **데이터를 만들었다**. 트윈이 자라고, 색인되고, 코드 작성 에이전트에게
전달된다. 이번은 그 트윈으로 **실제 코드를 대량 생산하고, 그 결과를 믿을 수 있게** 만든다.

    마일스톤 2   요청 하나 → 워커 하나 → 결과 하나          (1분 29초 실측, 한 줄로 이어짐)
    마일스톤 3   요청 하나 → **N 조각** → 워커 2대 → 순차 적용 → **3층 판정**

🔴 **얻는 것은 처리량이 아니라 증분이다** (사용자 재정의 2026-08-11). 실측이 처리량 쪽을
부정한다 — 워커 2대는 **12% 빠르고 90% 비쌌고**, 3.2배 절감은 **묶음**의 이득이지 병렬의
이득이 아니며, 층3 은 어차피 `.2` 한 대다. 이 마일스톤의 장치들(동결 · 골조 빌드 게이트 ·
의존 순서 · 통합자가 통과분만 커밋)은 전부 **"작업이 항상 컴파일되는 상태로 쌓이게"** 하는
것이다. 그래서 **검증은 선택이 아니라 전제다** — 검증 없이 쌓으면 증분이 아니라 부채다.
상세 = [`../4-work-loop.md`](../4-work-loop.md) §4.5 · [`../settled-decisions.md`](../settled-decisions.md).

✅ **"판정이 워커의 자기 신고뿐" 이던 것은 고쳐졌다** (2026-08-12). 이제 파이프라인에 **결정적
게이트가 둘** 박혀 있다 — 골조 빌드(소 1.1.5)와 **조각별 빌드 후 커밋**(소 1.4.3). 마커는
*"응답을 받았는가"* 만 판정하고, *"컴파일되는가"* 는 **통합자가 UE5 로** 판정한다.

✅ **대 2 도 닫혔다** (2026-08-12) — 이제 게이트가 **네 겹**이다: 골조 빌드 · 층1(응답 수락 +
적용 직전) · 층2(상용 모델, 선언부 grounding) · 층3(조각별 UE5 빌드 + work 단위 RunTests).
*"결정적 게이트가 LLM 판단보다 위"* 라는 규칙이 **파이프라인에 박혔다.**

🔴 **그런데 구멍이 하나 남았고 그것은 코드로 메울 수 없다** — **이 프로젝트에 자동화 테스트가
0개다**(실측). §4.3 이 실측한 *"컴파일을 통과하는 환각"*(`Cast<IInteractable>` · `IsValid()` 로직
오류)은 **테스트만** 잡을 수 있는데, 잡을 테스트가 없다. 층2 가 일부를 가져가지만 전부는 아니다.
⚠️ 그래서 층3 의 `RunTests` 는 지금 **fail-open** 이고, 그 사실이 판정마다 출력에 실린다.

## 🔴 토폴로지가 바뀌었다 — **쓰는 주체는 하나다** (사용자 확정 2026-08-11)

    옛것   워커 N대가 각자 자기 클론에서 수정 → 각자 커밋 → attempt push → 마커로 판정
    새것   워커는 **추론만** → 통합자(`.2`)가 **적용 → UE5 빌드 판정 → durable 커밋**

**빌드해 본 주체가 커밋한다** — 그래서 깨진 것이 원격에 **못** 박힌다. 옛 구조에서는 그것이
규율이었고(소 1.1.5·2.3.5 를 따로 칸으로 만든 이유), 새 구조에서는 **구조**다. 근거·비용·왜
`.33` 이 아니라 `.2` 인지는 [`../8-git-authority.md`](../8-git-authority.md) §8.4 와
[`../settled-decisions.md`](../settled-decisions.md).

이 결정이 **아래 분류를 바꿨다**: 중 1.3 은 「추론 파견」만 남고, 적용·빌드·커밋은 **중 1.4
통합자**로 나갔다. 🔴 **이미 닫힌 중 2.5 의 일부가 유휴가 된다**(워커 git 인증 · 찌꺼기 정리)
— **지우지 않고 보류**한다. 되돌릴 수 있어야 한다.

### 대 1. 대규모 작업 파이프라인 (§4.5) ✅ **닫혔다** (2026-08-12)

중 1.1 골조+동결 **6/6** · 1.2 분해 **4/4** · 1.3 추론 파견 **5/5** · 1.4 통합자 **4/4**.
요청 → 골조(`claude:opus`, 등재 전 빌드) → 분해 → 워커는 **추론만** → 스풀 → 통합자가
**적용·빌드·커밋**. 🔴 **서사는 리포트 12·13 에 있다** — 여기엔 **다시 걸릴 것만** 남긴다.

- 🔴 **내용은 양방향 모두 파일로 나른다.** `.2` 콘솔이 CP949 라 stdout 은 한국어에서 깨진다
  (층3 이 같은 자리에서 죽었다). 응답은 `.ax/work/<task>/response.txt` → `scp`
- 🔴 **마커는 "stdout 의 마지막 두 줄" 이라고 못박아야 한다.** *"출력의"* 라고만 쓰면 워커가
  **응답 파일의** 마지막 줄로 읽고, `RESULT: DONE` 이 `.cpp` 본문 끝에 박힌다(실측)
- 🔴 **큐는 `failed` 를 의존 해소로 센다**(*"영원 block 방지"*). 뎁스 후속은 **마스터가** 막는다
- 🔴 **스풀은 파생물이 아니다** — 돈을 낸 LLM 출력이고 *"어디까지 진행됐나"* 의 답이다.
  같은 기준 커밋의 통과분은 **다시 사지 않는다.** 기준이 다르면 **재사용하지 않는다**
- 🔴 **조각마다 빌드하고 조각마다 커밋한다.** §4.5 의 *"전부 적용 후 한 번"* 은 어느 조각이
  깨졌는지 모른다 — 증분 빌드 35~65초라 조각당 세워도 싸다. **첫 실패에서 멈춘다**
- 🔴 **되돌리기는 이번 조각의 파일만.** `reset --hard`·`clean` 은 범위를 넘는다.
  push 는 **ff-only · force 금지** — 거부되면 커밋은 트리에 남고 사람이 판단한다
- 🔴 **격리 트리는 파이프라인 소유일 때만 되돌려도 된다.** 사람의 트리에 같은 논리를 쓰지 말 것
- ⚠️ `parse_files` 의 `strip()` 이 EOF 개행을 지운다 → 관례 실측(하나 110·없음 36·빈줄 14)으로
  **하나로 정규화**했다. 완전 보존은 불가능하다
- ⚠️ **포팅 대응은 동명만으로 9쌍, 접두사 정규화로 21쌍**(파일 1,654개). 🔴 퍼지 매칭은 없다 —
  틀린 원본은 원본이 없는 것보다 나쁘다. **경로만** 싣는다(워커는 체크아웃을 읽는다)
- ⚠️ **워커당 캐시 생성 24~26K 토큰**을 각자 낸다 → 병렬은 워커 수만큼 그 값을 더 낸다.
  기본은 **직렬**. 시간 쪽은 옛 실측과 달랐지만(병렬 2건 36초 vs 단건 45초) **n=1 이라 A/B 전**
- ⚠️ **`.43` 은 추론 엔드포인트와 워커를 겸한다** — 35B 핀 13.2GB → MemAvailable 1.2GB.
  `claude -p` 는 RSS 317MB·스왑 0 으로 들어가지만, 🔴 **부하로 커널이 멈춘 전례**가 있다
- ⚠️ **push 는 `--dry-run` 까지만 실전 확인**(권한·ff 정상). durable `task/<id>` 는 요청자가 만든다

### 대 2. 3층 환각 검증 자동화 ✅ **닫혔다** (2026-08-12)

중 2.1 층1 **3/3** · 2.2 층2 **3/3** · 2.3 층3 **5/5**. 게이트가 **네 겹**이다 — 골조 빌드 ·
층1(응답 수락 + 적용 직전) · 층2(선언부 grounding) · 층3(조각별 빌드 + work 단위 RunTests).
서사는 리포트 13 §13.

- 🔴 **층1 은 두 곳에 박는다** — 응답 수락(`infer.judge`)과 적용 직전. ①이 없으면 잔재가 *"통과"*
  로 스풀에 쌓이고, ②가 없으면 스풀 손질·재사용 경로가 검사를 우회한다. **무료라 두 번 돌린다**
- 🔴 **`[FEEDBACK]` 이 소스에 남으면 위반이다** — 원전에서 *"모든 주석 보존"* 과 충돌해 **검증이
  무한 실패**한 자리다. 통합자가 안 넣는 것 + 층1 이 잡는 것, **양쪽**을 둔다
- 🔴 **차이를 만드는 것은 모델이 아니라 grounding 이다** (실측): 후보 5개 중 **넷이** 선언부 없이는
  *"없는 열거값"* 을 놓쳤고, 주면 잡았다. 층2 프롬프트에 선언부를 싣고 **못 실었으면 보고한다**
- 🔴 **층2 후보 실측**: agy·sonnet·opus **전부 동점**(검출 4/5 · 오탐 0) → 싼 쪽 먼저.
  14b 는 선언부를 줘도 못 잡고, **35B 는 정상 코드 2건을 막았다(오탐)** → 로컬은 층2 에 못 쓴다
- ⚠️ **인코딩이 유실된 사본으로 동결을 판정하지 않는다** — 치환된 글자가 선언 키를 바꿔 **없는
  위반**을 만든다. 그런 파일은 **동결 미검사**로 넘긴다
- ⚠️ **`frozen_decls` 는 키를 줄 단위로 뽑는다** — 한 줄에 몰아 쓴 선언은 동결되지 않는다
- ⚠️ **층2 쿨다운 600초.** 전부 쿨다운이면 `no_backend` 로 **차단**된다 — 그 차단이 값싼 이유는
  **스풀이 응답을 들고 있어서**다
- 🔴 **테스트가 0개다** (실측: `Source/` 에 `AUTOMATION_TEST` 0건). `RunTests` 는 `.2` 에서
  무인 구동 **74초**로 확인됐지만(DDC 비용 = 그 값) 판정할 것이 없다 → **불합격은 막고,
  돌 게 없으면 fail-open + 경고**. 🔴 §4.3 의 *"컴파일을 통과하는 환각"* 은 **테스트만** 잡는다 —
  **그 구멍은 코드로 메울 수 없다**(🕓 예정)
- ⚠️ **레드마인 등재는 키가 없으면 건너뛴다고 말한다** — 추적 실패와 게이트 통과는 다르다
