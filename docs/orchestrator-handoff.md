### ⑴ 고장 — 주석의 전제 하나

`bundle.hook_command_for` 가 훅 명령을 **상대경로**로 박고 있었고 근거 주석은
*"훅의 cwd 는 체크아웃 루트다"* 였다. **틀렸다** — 훅의 cwd 는 **세션의 현재 작업
디렉터리**이고 세션 도중에도 움직인다. `.33` 에서 그것을 옮긴 것은 사람이 아니라 **모델**이다
(Bash `cd …\Source\NS` 11:22:55 → **32초 뒤** 첫 차단). 파일을 못 열면 인터프리터가 exit 2 를
내고, `UserPromptSubmit` 에서 exit 2 는 **차단**이다.

[중요] **스크립트는 죄가 없었다** — `pending_works.py` 에 `sys.exit` 는 0건이다. `.33` 이 요청한
「훅을 fail-open 으로」는 **이미 그렇고**, 그걸 넣었으면 원인이 아닌 곳을 덮었을 것이다.
