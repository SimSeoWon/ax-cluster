# 작업 리포트 — 저장소 작업분

**저장소 코드에 대한 결정·실측·함정** 기록. 3자 동기(마스터·GitHub·BC-250)에 포함된다.

[중요] **왜 여기로 옮겼나 (2026-08-08).** 원래는 `~/claude-workspace/reports/` 에만 있었다.
그러면 두 가지가 깨진다:

1. **동기에서 빠진다** — 마스터 로컬에만 있어 이 기계가 죽으면 사라진다
2. **안 읽힌다** — 실측된 사실이다. 리포트 08 은 82KB 인데 "세션 시작 시 정독" 이 지켜진
   적이 없다. 2026-08-08 세션에서 리포트 07 을 `tail` 만 하고 넘어간 것이 드러났다

하드웨어·인프라 로그(01·03·04·05)는 저장소와 무관하므로 `~/claude-workspace/reports/` 에 남는다.
