# ax-work — 마스터 작업 수행 (워커 측 계약)

> 마스터가 생성해 배달한다. **손으로 고치지 말 것** — 다음 배달에 덮인다.
> 정본: `~/ax-cluster/master/client/skills/ax-work/SKILL.md` (마스터)

## 0. [중요] 이 스킬의 네 가지 전제 (사용자 확정 2026-08-09)

1. **이 머신에 프로젝트 소스 클론이 있다.** 없으면 작업하지 않는다
2. **마스터의 작업 요청은 네가 1차로 받고, 네가 오케스트레이션한다.** 마스터는 컨텍스트·큐·
   라우팅만 댄다 — 실행 판단은 이 머신의 몫이다
3. [중요] **컨텍스트 문서·도메인 규범은 어디까지나 참조다. 모든 판단의 기준은 소스 파일이다**
4. **너 혼자 다 하지 않는다** — 대량 생성은 `agy`/로컬 LLM 에 위임하고 **너는 검증한다**

## 1. 먼저 `./.ax/config.json` 을 읽는다

작업은 **체크아웃 디렉토리에서 시작한다.** 설정은 항상 같은 상대경로에 있다:

    ./.ax/config.json        이 머신·프로젝트 설정 (마스터가 생성)
    ./.ax/work/<task_id>/    작업 부산물은 전부 여기 (git 이 무시한다)

거기서 읽을 것: `master.services`(포트) · `checkout.path` · `capabilities` · `backends`.

[중요] **없으면 추측하지 말고 멈춘다.** 경로를 역산하거나 다른 머신의 값을 가져다 쓰지 말 것 —
그렇게 복사된 설정이 죽은 채 남아 있던 사고가 실제로 있었다(`.mcp.json` 이 다른 머신의
사용자 경로를 가리키고 있었다). 마스터에 배달을 요청한다.

## 2. [중요] 일감은 배달되어 온다 — 큐를 직접 부르지 않는다

    마스터: claim → 매니페스트 조립 → 파일 배달 → 너를 실행
    너:     manifest.md 읽기 → 작업 → push → 판정 마커 출력
    마스터: 마커를 읽어 큐에 submit

**네가 읽을 것은 딱 하나다:**

    ./.ax/work/<task_id>/manifest.md      컨텍스트 · 도메인 규범 · 골조 · 기준 커밋

[중요] **큐(8101)·MCP(8103)를 부르려 하지 말 것.** 이 머신에는 **베어러 토큰이 없다** — 실측
2026-08-09: 두 워커 모두 `8101/api/v1/health` 가 **401**, AX MCP 등록 **0건**. 401 을 받고
"인증을 설정해야겠다" 며 우회로를 찾지 말고, **매니페스트에 있는 것과 소스 파일로** 한다.
정말 부족하면 `RESULT: BLOCKED` 로 무엇이 없었는지 적는다.

이유: 토큰을 워커에 복사하지 않기로 했다. 리스 하트비트도 마스터가 대신 친다 — 너는
**작업에만** 집중하면 된다.

[중요] **능력을 부풀리지 말 것.** `./.ax/config.json` 의 `capabilities` 에 없는 일을 "되겠지" 로
시도하지 않는다. 특히 `ue5` 가 없으면 **층3 검증은 이 머신에서 불가능하다** — 되는 척하지
말고 그렇게 적는다.

## 3. [중요] 매니페스트는 지도다 — 판단은 소스로 한다

매니페스트에는 컨텍스트 문서 발췌와 도메인 규범(invariants)이 들어 있다. 그건
**어디를 볼지 알려주는 것**이지 사실의 원천이 아니다.

    지도(매니페스트)로  →  어느 파일·어느 클래스인지 좁힌다
    그 다음 반드시      →  Read 로 그 소스 파일을 직접 읽는다

**실측된 이유**(2026-08-09): 규범만 주고 로컬 모델에 코드를 시켰더니 실재 멤버 4/4 를 쓰고
invariant 도 지켰지만, `CurrentStep`(실제는 `Step`) · `EMissionTaskExecutorState`(실제는
`EMissionExecutorState`) 처럼 **한 글자 차이로 지어낸 이름**이 남았다. 정확한 철자는
**헤더에만 있다.** 너는 파일을 읽을 수 있으니 그 오류를 낼 이유가 없다.

- 시그니처·멤버명·enum 값은 **선언부를 열어 확인**한다
- 규범(invariant)과 소스가 어긋나면 **소스가 이긴다.** 어긋난 사실을 제출물에 적는다
- 매니페스트가 *"규범 grounding 없이 진행된다"* 라고 적혀 있으면 그대로 믿고, **소스를 더 읽어**
  메운다

## 4. 위임하고 검증한다 (모토: 무료=대량 생산, 상용/너=검증)

`./.ax/config.json` 의 `backends` 가 이 머신에서 쓸 수 있는 것을 말해 준다.

| 백엔드 | 쓰는 자리 |
|---|---|
| **로컬 LLM** (`backends.ollama`) | 반복적 본문 채우기, 대량 변환. 무료다 |
| **`agy`** (`backends.agy` 가 true 일 때) | 큰 파일 조사·정리. [중요] **`--add-dir` 로 파일을 쥐여줄 것** — 웹에서 찾으라고 시키면 출처를 지어낸다(실측). `-p` 는 **프롬프트 직전**에 둔다 |
| **너(Claude)** | 오케스트레이션 · 소스 대조 · 최종 검증 |

[중요] **위임 결과의 "완료" 를 믿지 말고 산출물을 확인한다.** `agy` 가 `status:"SUCCESS"` 를
반환하면서 파일을 안 쓴 사건이 있다. 파일이 생겼는지, 내용이 맞는지 **네가 본다.**

[중요] **결정적 게이트가 LLM 판단보다 우선한다.** 컴파일·테스트·린트가 있으면 그것이 최종 판정이고,
"모델이 괜찮다고 했다" 는 근거가 아니다.

## 5. 파일을 어디에 쓰나

| 산출물 | 위치 |
|---|---|
| **코드 변경** | 체크아웃 안. [중요] **`attempt/<task_id>/<workshop>/<timestamp>` 브랜치**에서 작업 |
| 로그·중간물·매니페스트 사본 | `./.ax/work/<task_id>/` — git 이 무시한다 |
| 그 밖 | **아무 데도 쓰지 않는다** |

[중요] **git 금지 목록** — 되돌리기 어려운 것은 하지 않는다:

    push --force · reset --hard · checkout(작업 브랜치 밖) · git clean ·
    브랜치/태그 삭제 · rebase · main 직접 push

특히 **`git clean` 은 절대 부르지 않는다.** 미추적 파일을 통과시키는 더티 체크의 전제가
그것이다. 그리고 사람이 편집 중인 미커밋 파일이 있을 수 있다 — `.uasset` 은 바이너리라
날리면 복구할 수 없다.

### [중요] 더티 판정의 범위는 **`Source/` 하위**다 (사용자 결정 2026-08-09)

    git status --porcelain -- Source/     ← 여기가 더러우면 BLOCKED
    범위 밖(Content/·루트의 .slnx·.uproject) → **막지 않는다**

이유: `.uproject`·`.slnx` 는 **UE5/VS 가 프로젝트를 열기만 해도 다시 쓰는 머신 지역 파일**이다
(실측: `.uproject` 의 diff 는 `EngineAssociation` GUID → `"5.8"`). 그걸 감시하면 게이트가
**항상 빨간불**이 되고, 항상 빨간 게이트는 게이트가 아니다. 색인·그래프도 이미 `Source/`
한정이다 — **같은 경계를 쓴다.**

[주의] 대신 이것을 지킨다: 범위 밖 파일을 **네가 고치지 않는다.** 그리고 `git checkout` 이
*"local changes would be overwritten"* 로 **거부하면 그건 진짜 막힌 것**이다 — 강제하지 말고
`RESULT: BLOCKED` 로 그 원문을 적는다.

[중요] 마스터도 **같은 범위**로 파견 대상을 고른다. 네가 더 넓게 보고 거부하면 *마스터는 보냈는데
워커는 거절하는* 왕복만 생긴다 — 실측 2026-08-09에 실제로 그렇게 한 번 헛돌았다.

### [중요] 시작 자세와 종료 자세 — 매번 **기준에서 출발해 기준으로 돌아온다**

    시작:  git fetch origin
           git checkout <기준 브랜치>            ← 매니페스트의 durable `task/<id>`
           git merge --ff-only origin/<기준>     ← [중요] ff 가 안 되면 BLOCKED. reset --hard 금지
           git checkout -b attempt/<task_id>/<workshop>/<timestamp>

    끝:    git push -u origin <attempt 브랜치>   ← 성공이든 실패든 **먼저 밀어 둔다**
           git checkout main                     ← [중요] **main 으로 돌아온다** (기준 브랜치가 아니라)
           그 다음에야 ATTEMPT/HEAD/RESULT 세 줄을 낸다

[중요] **복귀를 마커보다 먼저 한다.** 마커는 **출력의 마지막 세 줄**이어야 하는데(§6), 복귀를
나중에 하면 그 뒤에 무언가 붙을 여지가 생긴다. push 로 커밋은 이미 안전하므로 순서를
바꿔도 잃는 것이 없다.

[중요] **attempt 브랜치 위에 체크아웃을 두고 나오지 말 것.** 실측 2026-08-09: 시험 파견 후
`.43` 이 attempt 브랜치에 남았고, 그대로 두면 **다음 작업이 무관한 이전 시도 위에서 가지를
친다** — 두 작업이 한 줄에 쌓여 검증도 되돌리기도 어려워진다. 커밋은 push 로 이미 남았으니
돌아와도 잃는 것은 없다.

[중요] **돌아갈 곳은 `main` 이다** (사용자 결정 2026-08-09). `task/<id>` 에 앉아 있으면 마스터의
정리기가 **그 브랜치를 영영 못 지운다**(체크아웃된 브랜치는 삭제 대상에서 빠진다). `main` 에
서 있어야 병합이 끝난 `attempt/*`·`task/*` 가 정리된다. 작업물은 이미 원격에 있다.

## 6. 제출 — [중요] 마지막 세 줄이 계약이다

작업이 끝나면 **attempt 브랜치를 push 하고**(성공이든 실패든 — 증거를 버리지 않는다),
출력의 **마지막 비어 있지 않은 세 줄**을 정확히 이렇게 낸다:

    ATTEMPT: attempt/<task_id>/<workshop>/<timestamp>
    HEAD: <push 한 커밋 sha>
    RESULT: DONE

못 끝냈으면 `RESULT: BLOCKED` 이고, **그 위에 왜인지 적는다.**

[중요] **마스터는 이 마커만 읽는다. fail-closed 다** — 마커가 없거나·마지막 줄이 아니거나·철자가
다르면 **BLOCKED 로 처리된다.** 산문으로 "성공적으로 완료했습니다" 라고 써도 성공이 아니다.
거짓 완료가 큐에 쌓이면 다음 태스크의 `depends_on` 이 잘못 풀린다.

`RESULT: DONE` 인데 `ATTEMPT`/`HEAD` 가 없으면 **제출할 근거가 없어** 역시 막힌다.

제출물(마커 위 본문)에 **반드시** 담을 것:

- 무엇을 바꿨나 (파일·브랜치)
- **소스로 확인한 것** — 어떤 선언부를 읽고 무엇을 맞췄나
- 규범과 소스가 어긋난 지점이 있었으면 그 사실
- 위임한 것이 있으면 **무엇을 어디에 맡겼고 어떻게 검증했나**
- 결정적 게이트(빌드·테스트)를 돌렸으면 그 **원문 판정**. [중요] 요약하지 말 것 —
  `ssh` 종료 코드는 **양방향으로 못 믿는다**(빌드 실패에 0, 테스트 성공에 1이 나온 실측이 있다).
  로그의 판정 문자열이 근거다

## 7. 막혔을 때

[중요] **막혔을 때도 `RESULT: BLOCKED` 를 내고 끝낸다.** 조용히 멈추면 마스터는 타임아웃까지
기다리다 같은 판정을 내리는데, 그 사이 시간과 리스를 버린다.

- **설정·매니페스트가 없다** → 배달이 안 된 것이다. `BLOCKED` + 없는 경로를 적는다. 추측 금지
- **체크아웃이 낡았다** → `fetch` + **fast-forward 로만** 따라잡는다. [중요] 안 되면 `reset --hard`
  로 맞추지 말고 `BLOCKED` — 사람이 편집 중이던 것이 사라진다
- **능력이 모자란다**(UE5 없음 등) → 되는 척하지 말고 `BLOCKED` + 무엇이 없는지
- **소스와 지시가 모순** → 소스가 이긴다. 모순을 보고한다
- **401 이 돌아온다** → 정상이다(§2). 우회로를 찾지 말 것
