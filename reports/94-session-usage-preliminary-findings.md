## 범위와 방법

`/home/sim/ax-state/usage/raw/index.jsonl`에 있는 원본 654개(531,659,945바이트)를
읽었다. Claude 155개, Codex 499개이며 마스터와 `.2`·`.33`·`.43`의 수집 사본이다.
이번 사본의 사용량 시각은 UTC 2026-09-04 12:14:51부터 2026-10-04 16:31:40까지다.
전체 작업 역사를 모두 보존했다는 뜻은 아니다. 원본 보존 기간과 수집 범위에 제한된다.

기존 `master/work/session_usage.py`의 `PARSERS`를 호출했다. Claude는 파일 안에서
응답 `message.id`를 한 번만 세고, Codex는 누적값이 바뀌는 `token_count`의
`last_token_usage`를 센다. 별도 확인에서 Codex 턴별 합계와 파일별 마지막 누적값이
모두 일치했다(합계 580,308,507). 원본 JSON 파싱 실패 줄은 0개였다.

Claude 합계는 입력+출력+캐시 읽기+캐시 생성, Codex 합계는 입력(캐시 포함)+출력이다.
추론 토큰은 출력의 일부이므로 추가하지 않는다. 파견 로그는 합산하지 않았다.
기존 `usage_dashboard.py`도 두 출처의 중복을 피하도록 계열별 출처 하나를 사용한다.

효율 비교도 아니다. 세션 분리는 캐시 재사용을 잃을 수 있어 절감 효과를 미리 단정하지 않는다.

## 발견과 개선 방향

1. **파일 간 응답 중복을 집계에서 구분한다.** 바이트가 같은 파일(SHA256)은 없었지만,
   Claude의 `(host, message.id)`가 서로 다른 파일에서 다시 나타난 추가 출현은 360건이었다.
   이는 고유 중복 ID 360개라는 뜻이 아니다. 응답 값·출처가 같은지 대조하고 정상적인
   재개·분기 기록과 충돌을 구분해야 한다. 기존 파서는 파일 내부만 중복 제거하므로 현재
   합계를 보정 완료 수치로 쓰지 않는다. 원본 삭제는 필요하지 않다.
2. **세션에 프로젝트·일감 출처를 보강한다.** 미분류가 크고 work/task 연결이 없어 일감별
   효율을 판단할 수 없다. 향후 실행 시 확인 가능한 식별자를 남기고 현재 cwd 규칙과 함께
   표시한다. 과거 미분류를 대화 내용이나 활성 프로젝트로 자동 추정해 덮어쓰지 않는다.
3. **긴 세션의 맥락을 줄이는 운영안을 검토한다.** 작업 단위 분리와 짧은 인계서를 후보로
   두되, 캐시·비캐시 입력과 완료 품질을 함께 비교한다. 높은 캐시 비율만으로 원인을 특정하거나
   필수 문서 읽기 규칙을 바꾸지 않는다. 실제 적용은 별도 사용자 결정이다.
4. **도구 오류와 반복 조회를 간단히 보이게 한다.** Claude `tool_result.is_error`는 원본
   순회에서 357건이었다(파일 간 중복 보정 전). 실패 뒤 호출과 정상 상태 확인을 구분해
   요약할 수 있다. 오류 전부를 결함이나 낭비로 해석하지 않는다. 이번에는 사례별 심층 분석,
   실패 수정, 자동 재시도 정책 변경을 하지 않는다.

## 통계 한계와 정정

임시 집계 JSON(`/tmp/ax-usage-analysis-20261005.json`)의 도구 호출·반복·출력 크기 통계는
예비값이다. Codex `custom_tool_call` 4,476개와 대응 출력이 첫 집계에서 빠져 도구 호출
합계가 불완전하다. Claude 출력 문자열 크기에는 이미지 인코딩도 섞이므로 텍스트 토큰으로
환산할 수 없다. 해당 통계를 이 리포트의 확정 지표나 절감 근거로 사용하지 않는다.
임시 JSON은 재부팅 뒤 사라질 수 있으며, 핵심 수치와 한계는 이 리포트에 보존했다.

앞선 대화의 「긴 맥락 비용이 크다」는 개선 후보를 설명한 표현이다. 캐시 비율만으로
불필요한 맥락 비용이나 원인을 실증한 것은 아니다. 정확한 절감량은 산출하지 않았다.

첫 홈 전체 조회와 후속 `/tmp` 재귀 조회는 권한 오류로 각각 중단·보고했다. 사용자 후속
요청으로 기록 작업을 재개했으며, 이번 `/tmp` 경로 확인은 `--maxdepth 1`로 한정해 성공했다.
잘린 출력은 전문 확인으로 취급하지 않고 필요한 모듈 구간과 예비 집계 키를 나누어 읽었다.
