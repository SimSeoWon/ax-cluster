# 스킬 작성 규약

> 정본 한 벌. 스킬(SKILL.md)을 **새로 만들거나 고칠 때마다** 지킨다(사용자 2026-11-07, `#890`).
> 규약은 `master/test_skill_conventions.py` 가 강제한다 — 이 문서는 그 검사의 설명이다.

## 대상

`master/skills/*`(마스터 · `~/.claude/skills` 에 디렉터리 링크) · `master/client/skills/*`(요청자·워커 배달)
· `master/client/workshop/skills/*`(작업장 배달) 아래의 모든 스킬. 새 폴더를 만들면 검사가 자동으로 잡는다.

## 1. frontmatter

- `---` 로 시작하고 YAML 로 파싱돼야 한다. `name` 은 폴더 이름과 같고 소문자·숫자·하이픈 64자 이내.
- `description` 은 1,024자 이내 · 무엇을 하고 언제 쓰는지 · 3인칭.
- `description` 에 꺾쇠 자리표시(`<N>`)를 쓰지 않는다. 백틱으로 시작하지 않는다. 값 안의 `: `(콜론+공백)은
  YAML 을 깨므로 피한다(실측 — `audit-context` 가 백틱 시작으로, 고치는 중 `예: ` 로 한 번 더 깨졌다).

## 2. 구획 — 제목 · 본문 · 맨 앞 목차

- 본문은 `# 제목` 한 줄 다음 **곧바로 `## 목차`** 가 온다. 목차는 `- 제목` 줄만 담고, 그 뒤의 모든 `## 제목` 을
  **같은 글자·같은 순서**로 나열한다 — grep 으로 제목을 찾아 그 구획만 읽게 하려는 것이다.
- 제목 없는 본문 덩어리를 두지 않는다. 서문은 `## 개요` 구획으로 묶는다.
- 코드 펜스 안의 `#` 줄은 제목으로 세지 않는다.

## 3. 길이와 번들

- SKILL.md 는 500줄 미만. 100줄을 넘으면 앞 100줄 안에 목차와 `## 사용 예`(또는 `## 호출 방법`)가 있어야 한다.
- 넘치면 조건부로만 읽히는 구획을 `reference/*.md` 로 옮긴다. 원래 자리에는 제목·요약과
  「해당하면 그 파일을 읽고 따른다」를 남긴다(지침을 바꾸지 않는다 — 옮기기만 한다).
- 번들은 **한 단계**다: `SKILL.md` + `reference/` · `scripts/` 바로 아래 파일. 다른 폴더·더 깊은 폴더는 배달되지 않는다.
- SKILL.md 의 `reference/…` 링크는 실재해야 한다. 100줄 넘는 reference 파일은 맨 앞에 `## 목차` 를 둔다.

## 4. 정적 동작은 스크립트

- 정해진 호출(조회·기록·변경)은 `scripts/*.py` 로 두고 SKILL.md 에는 그 실행 줄만 적는다. 자유도가 필요한
  판단은 글로 쓴다.
- 인라인 `python -c` 를 쓰지 않는다 — 셸이 백틱을 명령으로 실행해 구절이 조용히 사라진다(두 번 당했다).

## 5. MCP 도구는 서버 이름과 함께

- 도구는 `서버:도구` 로 적는다 — `ax-projects:issue_start_tool` · `ax-client:issue_start`. 비슷한 이름이 두 서버에
  있어 혼동을 막는다. 서버 목록은 `master/projects/mcp_server.py`(@mcp.tool) · `client/runtime/client_mcp.py`(name).
- 요청자 세션에는 `ax-client` 만 붙는다(`spec.MCP_BY_ROLE`). 요청자 스킬이 `ax-projects:` 도구를 부르면 그 세션에서는
  도구가 없다 — 쓰기 전에 확인한다.

## 6. 배달

- 스킬은 배달물 = 실행 입력이다. 고치면 `master.client update`(마운트된 프로젝트) 로 배달하고 `check` 가 번들 파일마다
  해시를 대조한다. 비마운트 프로젝트의 요청자 스킬은 마운트 전환 때 맞춰진다.
- 「할 수 있다」는 정보가 「해라」로 읽힌다 — 금지는 명시하고, 개요·예시에 새 지시를 만들지 않는다.

## 7. 검사 돌리기

    .venv/bin/python master/test_skill_conventions.py

실패하면 스킬 이름과 어긴 항목이 한 줄씩 나온다.
