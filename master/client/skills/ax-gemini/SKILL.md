## 0. [중요] 먼저 묻는다 — 바로 위임하지도, 말없이 직접 하지도 않는다

요청이 아래에 해당하면 **작업을 시작하기 전에** 사용자에게 한 번 묻는다:

    리서치(주어진 소스·문서 조사) · 보고서/리포트 작성 · 문서 초안 · 코드 구조 분석·요약 · 비교 정리

묻는 내용 셋을 **한 번에** 낸다:

1. Gemini(agy)로 돌릴지 — 아니면 지금 세션이 직접 할지
2. 넘길 자료 — 파일·폴더 목록 (네가 고른 후보를 보여 주고 확인받는다)
3. 보고서 파일 이름 — 기본 `reports/research/YYYY-MM-DD-<주제>.md`

[중요] **사용자가 고른다.** 거절하면 지금 세션이 평소대로 처리한다. 한 번 답을 받은 같은 작업에서
다시 묻지 않는다. [주의] 짧은 `응` 은 바로 앞에 이 물음이 있었을 때만 승인이다.

**쓰지 않는 곳** — 묻지도 않는다:

- 코드 본문 작성 — 작성 레인(`codex`→`agy`→로컬)이 따로 있다
- 층2 검증·리뷰 — 교차 계열 조건(리뷰어는 작성자와 다른 계열)이 걸려 있다
- 웹에서만 알 수 있는 사실 — agy 는 **출처를 지어낸다**(실측 2026-08-07: 도메인 루트 위조 인용)
- 무인 경로(워커 파견·훅) — 물을 사람이 없다

## 1. 자료를 스크래치에 복사한다

[중요] **저장소를 통째로 주지 않는다.** `--dangerously-skip-permissions` 로 도는 자율 에이전트라
보이는 파일을 건드릴 수 있다. 세션 스크래치(없으면 임시 디렉토리)에 작업 폴더를 만들고
**사본만** 넣는다:

    <scratch>/ax-gemini-<주제>/
        BRIEF.md          지시서 (아래 §2)
        src/...           자료 사본 — 원래 상대 경로를 유지해 인용이 원본과 맞게

## 2. 지시서는 파일로 쓴다 — 명령줄에 싣지 않는다

[중요] 내용은 **`BRIEF.md` 파일**에 쓰고, 명령줄 프롬프트는 짧은 ASCII 한 문장이다.
명령줄에 한글·백틱을 실으면 셸이 백틱 구절을 **조용히 지우고**(두 번 당했다) Windows 콘솔은
CP949 로 깨진다. 파일은 Write 도구로 쓴다(셸 heredoc 아님).

`BRIEF.md` 에 반드시 넣을 것:

- 목적·질문 — 사용자의 말을 그대로 옮긴다
- 자료 범위 — `src/` 아래만 근거로 쓸 것
- **인용 규칙** — 주장마다 `src/경로:줄번호` 를 **링크 없이 일반 텍스트로** 단다(실측 2026-10-09:
  링크를 허용하면 스크래치 절대 경로 `file:///tmp/…` 링크를 만들어 커밋 뒤 열리지 않는다). 자료에서 확인 못 한 것은 「확인 불가」로 쓴다.
  추측은 「추측」이라고 표시한다
- 출력 — **보고서 본문 전체를 응답으로 돌려줄 것** · 파일을 만들거나 고치지 말 것 · 한국어 Markdown
- 보고서 골격 — 요약 · 본문(질문별) · 근거 목록 · 확인 불가·한계

## 3. 실행한다 — 시작·종료를 한 줄씩 알린다

시작 전에 사용자에게 한 줄: *"agy 실행 — 자료 N개 · 지시서 <경로>"*.

**마스터 — 반드시 이 모듈로, 백그라운드로 돌린다** (agy 를 직접 부르지 않는다):

    cd ~/ax-cluster && AX_PROJECTS_ROOT=$PWD .venv/bin/python -m master.work.gemini_report --project <마운트된 프로젝트> \
        --brief-dir <scratch>/ax-gemini-<주제> --out reports/research/YYYY-MM-DD-<주제>.md

[중요] **백그라운드 실행이 기본이다** (사용자 요청 2026-10-09, `#762` 후속). Claude Code 는 Bash 의
`run_in_background` 로 돌리면 프로세스가 끝날 때 세션을 다시 깨운다 — 그것이 완료 통지다.
기다리는 동안 폴링하거나 `sleep` 하지 않는다. 깨면 **`[ax-gemini]` 로그 줄과 결과 JSON 만** 읽는다 —
결과 JSON 은 **`{` 로 시작하는 마지막 줄**이다(`grep '^{' <출력> | tail -1`). [주의] 출력 파일의
마지막 줄이 아니다 — 하네스가 끝에 `[exited with code N]` 을 붙인다(실측 2026-10-09).

종료 코드: **0** 성공 · **1** 실패(보고서 없음, §5) · **2** 실행 전 거절 · **3 경고** — 보고서는 썼지만
agy 봉투 `status` 가 `SUCCESS` 가 아니다(실측: `ERROR` + 503 용량 부족 + 본문 5,401자). 결과 JSON 은
`ok:false`, `why`·`error` 에 원문, 머리말에 `[주의]` 줄, `usage_log` 비고에 같은 문구가 남는다.
[중요] **agy 가 스스로 재시도해 회복했으면 0 이다** (사용자 결정 2026-10-09 A). 모듈이 실행마다
`--log-file <보고서>.run/agy.log` 를 받아 「attempt N 실패 → 재시도 → 이후 생성 요청」을 확인하면
성공으로 보고, 머리말 `> 참고:` 줄·결과 JSON `retries`/`recovered`·`usage_log` 비고에 재시도 횟수를
남긴다. 실측 2026-10-09: 503 용량 부족이 3회 중 2회 — 둘 다 재시도로 회복했다. 회복 근거가
모자라면 종전대로 3 이다. 모델 이름(`gemini-…`)도 그 로그에서 읽는다(봉투에는 없다).
🔴 [중요] **모델은 정본 id 로 명시된다** (`#830`) — 모듈이 `agy --model <id>` 를 싣는다(마스터는 정본,
`--remote` 는 `.ax/config.json` `backends.agy_model`). 값이 없거나 별칭·Argon 이면 **종료 2**(agy 안 부름),
로그의 실제 모델이 요청과 다르거나 로그가 없어 모르면 **종료 1**(보고서 없음 · `.run/` 보존) — 둘 다
사유를 그대로 보고한다. Argon 은 사용자가 명시적으로 요청할 때만 `--model <id> --allow-argon` 으로 준다.
그 호출이 한도(429·쿨다운)에 걸리면 `gemini-3.8-flash-high` 로 한 번 넘어간다(`#920`) — 결과의
`fallback_from` · `actual_model` 을 사용자에게 보고한다. 첫 시도 기록은 `.run.argon-<시각>/` 에 남는다.
[주의] Codex 세션의 백그라운드 완료 통지는 확인되지 않았다 — 안 되면 포그라운드로 돌린다.

[중요] 모듈이 **기록을 강제한다** — 성공·실패 모두 트윈 `usage_log.jsonl` 에 한 줄
(`source=ax-gemini` · `lane=agy` · 토큰 · 소요 · rc)이 남고 대시보드에 잡힌다. stderr 에 시작·
30초 하트비트·종료 로그를 찍고, 원본 봉투·stderr·지시서를 `<보고서>.run/` 에 보관한다(커밋 안 함).
보고서 본문과 머리말(작성·자료·「검증: 미검증」+ 인용 범위 자동 검사·소요·토큰)도 모듈이 쓴다.
마지막 줄 결과 JSON 에는 `summary`(요약 절, 600자 이내) · `citations`(인용 수·범위 밖·파일 없음) ·
`citations_file`(인용된 원문 줄 모음)이 실린다.
[주의] 마운트되지 않은 프로젝트·`reports/research/` 밖 경로·이미 있는 파일은 실행 전에 거절된다.
🔴 [중요] **Windows 세션 0(SSH·비대화형)에서는 모듈이 종료 2 로 거절한다** (`#832`) — agy 로그인은 그 PC 의
대화형 세션 자격이라 세션 0 에서는 늦게 엉뚱하게 죽는다. **그 PC 의 대화형 세션에서 실행한다**(SSH 로 돌리지 않는다).

**`.33` 요청자 — 배달된 같은 모듈을 `--remote` 로 돌린다** (`#763`, agy 를 직접 부르지 않는다).
체크아웃 루트(cwd)에서, `.ax/config.json` 의 `backends.python` **절대경로**로 실행한다(`py` PATH 에 기대지 않는다):

    "<backends.python>" -c "import sys; sys.path.insert(0, '.ax/lib'); from axmaster.work import gemini_report as G; sys.exit(G.main())" \
        --remote --brief-dir <scratch>/ax-gemini-<주제> --out reports/research/YYYY-MM-DD-<주제>.md

  [중요] 기록은 **큐를 거쳐 마스터 트윈** `usage_log.jsonl` 에 남는다 — 모듈이 `POST /api/v1/usage` 로
  한 줄(`source=ax-gemini` · `lane=agy` · `worker=<이 기계 this_host.host>` · 토큰 · 소요 · rc · 모델 · 비고)을
  보내고 마스터가 대행해 쓴다. 성공·실패 모두 보낸다. 프로젝트 태그는 `.ax/config.json` 의 `project` 다
  (`--project` 는 주지 않는다 — 다르면 거절). 종료 코드·결과 JSON·머리말·`.run/` 보관·인용 검사는 마스터와 같다.
  [주의] 전송이 실패해도 실행은 실패가 아니다 — stderr `[주의] 사용량 기록 실패` 줄과 결과 JSON `usage_error`
  에 사유가 남는다. 그 값이 있으면 사용자에게 보고에 함께 싣는다(대시보드에 그 실행이 안 잡힌다).
  [주의] 마스터 큐가 이 체크아웃의 프로젝트를 마운트하고 있지 않으면 큐가 `not_mounted` 로 거절한다 —
  보고서는 써지고 `usage_error` 에 그 사유가 실린다.

[중요] **`-p` 는 프롬프트 바로 앞이다** — 앞에 두면 다음 토큰을 프롬프트로 먹는다(실측 2026-08-08).
[주의] 오래 걸린다(수십 초~수 분). 시작할 때 「백그라운드로 돌린다」고 한 줄, 끝나면 한 줄 알린다.

## 4. 검증한다

1. 보고서는 **모듈이 쓴다** — agy 가 파일을 쓰게 하지 않는다(지시한 경로가 아닌 곳에 쓴
   사례가 있다). 기준은 **지금 작업 중인 저장소 루트**다(마스터는 `~/ax-cluster`)
2. **종료 3(경고)이면 먼저 사용자에게 알린다** — `error` 원문과 함께. 본문이 잘렸을 수 있으니 결과
   JSON 의 `summary` 와 절 제목(`grep '^## '`)으로 골격이 온전한지 보고, 대조를 **5개 이상**으로 늘린다.
   쓸지 버릴지는 사용자가 정한다
3. 🔴 [중요] **보고서 본문을 통째로 읽지 않는다** — 인바운드 토큰이다(사용자 요청 2026-10-09).
   범위 검사는 모듈이 이미 했다(결과 JSON `citations`). 범위 밖·파일 없음이 있으면 그것부터 본다.
4. **인용 3개 이상의 내용을 대조한다** — `citations_file` 에서 **해당 절만**(`### <인용>` 머리부터
   다음 `###` 전까지) 읽고, 보고서에서는 그 인용이 달린 **문장만** `grep -n` 으로 찾아 본다.
   그 줄이 그 주장을 하는지가 판정이다. [주의] 범위 안이어도 틀릴 수 있다 — 실측 2026-10-09 에
   `runner.py:356-358` 은 범위 안이었지만 실제 근거는 360-361 이었다.
   [중요] `status:"SUCCESS"` 나 그럴듯한 문장은 근거가 아니다(실측: SUCCESS 인데 파일이 없었다)
5. 머리말의 **「검증」 줄 하나만** 대조 결과로 고친다 — Edit 로 그 줄만 바꾼다
   (마스터·`.33` 모두 머리말은 모듈이 썼다):

       > 작성: Gemini (agy <버전>) · 위임·검증: <세션 Claude/Codex> · <날짜>
       > 자료: <원본 경로 목록>
       > 검증: 인용 N개 대조 — 일치 a · 불일치 b (불일치는 본문에 [검증 불일치] 표시)
       > 소요 <초> · 토큰 입력 <n> / 출력 <n> (못 읽었으면 「미상」 — 0 으로 쓰지 않는다)

6. 사용자에게 **요약(결과 JSON `summary`) + 파일 경로 + 검증 결과**를 보고한다. 보고서 전문을 대화에 붙이지 않는다

[중요] **불일치를 네가 몰래 고쳐 덮지 않는다.** 표시하고 보고한다. 고쳐 쓰기를 원하면 사용자가 정한다.

## 5. agy 가 안 될 때

`agy` 없음 · 한도(429) · 인증 실패 · 시간 초과 · 봉투 아님 — **사유를 그대로 보고하고 멈춘다.**
그 자리에서 지금 세션이 직접 쓸지 묻는다. 말없이 직접 써서 「Gemini 가 썼다」처럼 보이게 하지
않는다. `<보고서>.run/err.log` 끝부분을 보고에 싣는다.
