  클래스 그래프 1,341줄. 데이터는 `--export-state` 로 **받아왔을 뿐**이라
  트윈이 **2026-08-08 12:56 스냅샷에 얼어 있다**
- **온톨로지 247 yaml 이 검색 0건** — `domain_index.py`(829줄) 미이식
- **화면이 없다** — 웹 UI 892줄 미이식
- e2e 자기검증(416줄) 미이식 — 그래서 "돈다" 를 끝까지 증명하지 못했다

## ⚠️ 이 마일스톤에서 배운 것 — 진행 방식에 대한 것

- **범위를 결과에 맞춰 좁히지 말 것.** 작업 루프를 만든 뒤 그것을 "서버측" 이라 부르고
  완결 선언을 했다. 온톨로지·문서 생성·그래프가 전부 서버측인데도. 분모를 줄여 완성률을
  만들면 남은 일이 안 보인다
- **조사 대신 라벨을 붙이지 말 것.** `ontology_*` 4,832줄을 열어보지도 않고 "2단계" 로
  미뤘다. 나중에 열어보니 합성/색인/조회/관리가 갈리고 필요한 건 829줄뿐이었다
- **원본이 남긴 경고를 먼저 찾을 것.** `import_state` 독스트링이 *"도메인 인덱스는 명시
  호출해야 한다"* 고 적어 뒀는데 안 읽어서 온톨로지가 0건이었다
- **"완료" 는 영역 전체에만.** 부분이면 분모를 같이 적는다
