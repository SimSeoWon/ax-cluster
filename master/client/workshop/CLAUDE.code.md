## AX 클러스터 — 이 체크아웃은 **`kind: code`** 프로젝트다 (UE5 아님 · 분산 작업 있음)

이 프로젝트는 AX 클러스터에 **UE5 가 아닌 소스 프로젝트**로 등록돼 있다 (`#695`, 사용자 결정
2026-09-30). 분산 작업을 받는다 — 단 **받는 확장자는 `.py` 뿐**이다(1단계). 다른 확장자가 섞인
명세는 마스터가 등재를 거절한다. C++ 서브모듈(`vendor/kimodo.cpp`)은 이 파이프라인의 대상이 아니다.

[주의] 2026-09-30 전의 판은 이 프로젝트를 `kind: index_only` 로 적었다. **지금은 이 블록이 정본이다.**

### 흐름 — 정본 7단계, `.py` 판

| 단계 | 자리 |
|---|---|
| 등재 | 스킬 `ax-request` → MCP `ax-client` 의 `register_work` |
| 골조 | `task/<work_id>/base` 에 `.py` 골조 커밋 — 모양은 `ax-request` §3.6 (`# [DOC]` · `# [PSEUDO]` · `raise NotImplementedError`) |
| 골조 게이트 | push 전: `py -3.12 -m axmaster.work.skeleton_gate --py <파일…>` (`PYTHONPATH=.ax\lib`, HEAD 를 잰다). 마스터도 파견 전에 같은 판정을 강제로 돌린다 |
| 파견 | 골조 push 가 트리거다 — 워커 `.2`·`.43` 이 조각마다 서브 브랜치에 커밋한다 |
| ⑦ 전진 | 스킬 `ax-advance` — 통합 검사는 UE 빌드가 아니라 `.ax/config.json` 의 `tests`(`unittest discover`)다 |
| 마감 | 스킬 `ax-review` → `finalize` (`main` 머지) |

### 사실로 알아 둘 것

- 함수·메서드·클래스의 **이름·인자·기본값·반환 표기는 골조에서 동결**된다. 워커가 바꾸면 층1 이 막는다.
- 통합 검사가 **0개 실행**이면 통과가 아니다. 서버·실행파일을 띄우는 테스트는 없다.
- `ax-client` 는 **로컬 스코프**로 등록돼 있다(`~/.claude.json`) — 이 레포의 `.mcp.json` 은
  사람 것이고 마스터가 건드리지 않는다. 같은 이유로 루트 `CLAUDE.md`·`AGENTS.md` 도 건드리지 않는다.
- 도구 본체는 `.ax/lib/` 에, 프로젝트 태그·테스트 설정은 `.ax/config.json` 에 있다. 둘 다 git 밖이다.
- 검색·갱신은 마스터가 **마운트한 프로젝트만** 한다. 마운트돼 있지 않으면 검색·등재가
  `not_mounted` 로 거절된다 — 고장이 아니라 그 상태의 결과다(마운트를 옮기는 것은 사람의 결정이다).
