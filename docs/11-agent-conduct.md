# 11. 에이전트 행동 수칙 — 묻기 · 수정 권한 · 실행 권한

> [중요] **원전 `.agents/AGENTS.md`(21줄) 이식분이 여기 모여 있다** (소 4.1.1 / `#173`, 2026-08-14).
> `CLAUDE.md` 양쪽에는 **규칙 한 줄씩만** 남기고 근거·실측·범위는 이 문서가 든다 — 그 파일들은
> 매 세션 자동 로드되므로 길이가 곧 모든 작업의 세금이다.
>
> [주의] **이 문서는 규칙의 근거지 규칙의 출처가 아니다.** 규칙 자체는 `CLAUDE.md` 에 있고, 여기 없는
> 규칙을 여기서 만들지 않는다. 커밋 권한의 **경계**는 [`8-git-authority.md`](8-git-authority.md) 가
> 소유한다 — 이 문서는 *"사람 세션이 어떻게 행동하나"* 쪽이다.

## 11.1 묻기 — 애매하면 묻는다

**사용자 지시 2026-08-13, 세 번 반복된 실패.** 그리고 [중요] **원전 3조가 같은 규칙을 이미 문서로
갖고 있었다**: *"사용자 입력이 작업 지시인지 단순 질문인지 모호한 경우, 임의로 해석하여 행동에
나서지 말고 반드시 질문을 던져 의도를 재확인하십시오."*

애매함은 **두 종류**이고, 우리 규칙은 오래도록 첫 번째만 덮고 있었다:

    ① 설계의 애매함    갈림길이 있으면 멈추고 묻는다. "내 판단으로는 이게 맞다" 로 진행하지 않는다
    ② 입력의 애매함    [중요] **작업 지시인가 단순 질문인가** — 원전 3조가 명시한 쪽

### [중요] 짧은 수긍이 가장 위험하다

`응` · `그래` · `ok` — **앞에 물음이 없었으면 그것은 승인이 아니라 수긍일 수 있다.**

**실측 2026-08-14** (한 세션 안에서): `응` 이 두 번 왔다. 첫 번은 커밋 승인이었고 **두 번은 단순
수긍**이었다(앞 메시지에 물음이 없었다). 두 번째를 승인으로 읽었으면 **다음 마일스톤 작업을 임의로
시작**했을 것이다. 세 번째 `응` 은 물음이 **둘** 있는 자리에 왔고, 그중 하나(선택지형)는 답이 안 된
것으로 처리했다.

[중요] 이것은 원전이 낸 사고와 **같은 계열**이다 — *"중간 커밋하고 올게"* 라는 **1인칭 서술**을 지시로
오독해 임의로 커밋했고, 사용자가 *"다 지워진 줄 알고 깜짝 놀랐다"* 고 항의했다. 판별법은 하나다:
**내가 방금 무엇을 물었는지 확인하고, 그것과 답이 맞물리는지 본다.**

## 11.2 만들기 전에 읽는다 — 원전과 기존 자산

이 저장소에는 원전(`~/AgentTest`)이 있고 **대부분의 요구에는 이미 만들어진 것이 있다.** 안 읽고

## 11.3 수정 권한 — 자동 로드 문서와 게임 소스

**원전 1조 이식, [중요] 범위는 사용자 결정 2026-08-14.** 이 둘은 **고치기 전에 계획을 말하고 동의를
받는다**:

    ① 자동 로드 문서   `CLAUDE.md` 전부 — 이 저장소의 것 · `machines/sim-desktop.md`
                       (= `~/CLAUDE.md` 심볼릭 링크) · 기계에 복사되는 `machines/win-*.md` ·
                       프로젝트 `repo/CLAUDE.md`
    ② 게임 소스        `ModularStage` 의 소스·에셋 — 미러든 워크트리든 원격 체크아웃이든

### [중요] 왜 이 둘만이냐 (전면 적용하지 않은 근거)

원전 1조는 *"프로젝트 내의 어떠한 파일도"* 를 덮는다. 그러나 그 조항이 겨눈 조건은 **사람의 UE5
프로젝트를 에이전트가 직접 만지는 상황**이었다. 우리에게 그 조건이 실재하는 자리가 정확히 이 둘이다:

- **①은 되돌리는 비용이 가장 크다** — 한 줄이 **모든 다음 세션의 행동을 조용히 바꾼다.**
  [주의] 이 범위를 고른 근거가 실제 사건이다: 2026-08-14 세션이 자동 로드 문서 4곳을 **사전 동의 없이**
  고쳤고(토폴로지 정정), 사용자가 그것을 보고 범위를 이 둘로 정했다.
- **②는 사람의 작업물이다** — 미커밋 `.uasset` 은 복구 불가다(`.33` 게스트 규칙과 같은 근거).

도구 코드(`master/`·`docs/`·`reports/`)는 **커밋 승인 게이트가 이미 그 역할을 한다** — 커밋 전에는
아무것도 영구화되지 않는다. [중요] 이것은 *"안 옮기는 판단에도 근거가 필요하다"* 의 적용이지 규칙을
깎은 것이 아니다.

## 11.4 승인과 검토 비용

**원전 4조 이식**: *"개발자가 코드리뷰 스트레스(검토 비용)를 겪지 않도록 변경 대상을 명확히 밝히고
상세한 전후 사정을 투명하게 설명하십시오."*

승인을 구할 때 **무엇을 · 어디를 · 왜**와 **측정 결과**를 함께 낸다.
[중요] *"커밋할까요?"* 만 던지면 사용자가 diff 를 직접 감사해야 하고, **그건 승인이 아니라 전가다.**

## 11.5 실행 권한 — 커밋 · 빌드 · 데몬

경계의 **정본은 [`8-git-authority.md`](8-git-authority.md)** 다. 여기서는 사람 세션의 행동만 적는다.

| | 우리 규칙 | 원전 |
|---|---|---|
| `git commit` / `push` | **묻고, 승인 후 실행** | [중요] 더 강하다 — *"사용자가 시켜도 금지, 묻지도 말 것"* |
| `push --force` · `reset --hard` · 브랜치·태그 삭제 · `rebase` · 히스토리 재작성 | [중요] **승인이 있어도 안 한다** — 명령만 적어 준다 | 같다 |
| 빌드 · 배포 · 데몬 종료·재기동 | **묻고, 승인 후 실행** | [중요] 더 강하다 — *"빌드할까요?" 같은 질문 형태조차 금지* |

[중요] **커밋 완화는 사용자가 직접 정한 것이다** (2026-08-14: *"커밋은 나에게 허락을 요구해줄래?"*).
원전의 윈도우 박스에는 소스트리가 있고 sim-desktop(리눅스)에는 없어서, *"절대 금지"* 면 사용자가
매번 터미널로 내려가야 한다. **라벨을 똑바로 둘 것 — 완화한 것은 사용자이고 내가 아니다.**

빌드·배포 쪽도 같은 결로 「묻고 나서 실행」을 택했다. 원전이 그 규칙을 만든 계기는
*"운영 인프라 PC 의 데몬을 승인 없이 교체·재기동해 강한 항의"* 였고 목적은 **위험 분리**다 —
비싸고, 공유 상태를 건드리고, 사람이 그 기계를 쓰고 있을 수 있다(`.2` 의 UE5 빌드, 마스터의 서비스).

[주의] **파이프라인이 커밋하거나 빌드하는 것은 이 절과 무관하다** — 통합자·작업장·골조 게이트·층3 은
**설계된 동작**이다. 이 절은 **대화형 세션**을 묶는다.

## 11.6 원전 5조 대조표 — 무엇을 옮기고 무엇을 안 옮겼나

[중요] **다섯을 뭉텅이로 옮기지 않았다.** 조항마다 *"그 조항이 겨눈 조건이 우리에게 있나"* 를 따졌다.

| 원전 조항 | 판정 | 어디로 |
|---|---|---|
| **1조** 임의 수정 절대 금지 | **범위 좁혀 이식** (사용자 결정) | §11.3 |
| **2조** 사전 동의 없는 툴 사용 금지 | [중요] **안 옮긴다** (아래) | — |
| **3조** 모호성 제거 | **이식** — 우리 건 절반만 덮고 있었다 | §11.1 |
| **4조** 상세한 사전 설명 | **이식** — 없던 규칙이다 | §11.4 |
| **5조** 직접 빌드·커밋 금지 | **부분 이식** — 커밋은 있었고 **빌드가 없었다** | §11.5 |

### [중요] 2조를 안 옮긴 근거

*"단순 파일 읽기(`view_file`·`list_dir`)나 검증 명령 실행이라 할지라도, 사용자가 인지하지 못한
상태에서 몰래 툴을 호출해서는 안 됩니다."*

그 조항이 겨눈 조건은 **사람이 툴 호출을 볼 수 없는 에이전트**다. Claude Code 는 **모든 툴 호출을
터미널에 그대로 띄운다** — *"몰래 호출"* 이 **구조적으로 불가능**하다. 옮기면 카고 컬트다.

[주의] 조항의 나머지 절반(*"무엇을 하려는지 사전에 간략히 설명해야"*)은 **이미 우리 관례**이고 §11.4 가
그것을 문서화한다. [중요] **재범위로 남기고 닫지 않는다** — 무인 잡(cron·타이머)에서 도는 세션은 사람이
보지 않으므로 **전제가 다르다.**
