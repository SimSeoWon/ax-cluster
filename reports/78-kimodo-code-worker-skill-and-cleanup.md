## 2. 수정한 설치 경계

`#698`은 Windows 부트스트랩이 새 체크아웃에 `CodexSandboxUsers` 수정 ACE를 부여하게 했다.
한 PC에서 수동으로 고친 ACL이 아니라 프로젝트 추가 때 재현되는 초기화 계약으로 옮겼다.

`#699`는 관리되는 Codex 자산을 프로젝트 안에 만들었다. `.agents/skills`와
`.codex/config.toml`을 배달하고, Git exclude와 프로젝트 cwd의 MCP 등록까지 검사한다.
홈 스킬이 우연히 존재하는지에 새 프로젝트의 성공 여부가 매달리지 않는다.
