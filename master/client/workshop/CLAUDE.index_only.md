## AX 클러스터 — 이 체크아웃은 **색인 전용** 프로젝트다 (`kind: index_only`)

이 프로젝트는 AX 클러스터에 **색인·검색까지만** 등록돼 있다 (`#693`, 사용자 결정 2026-09-28).
UE5 프로젝트가 아니라서 골조·파견·조각별 빌드로 이어지는 분산 작업 파이프라인은 여기서
돌지 않는다 — 마스터 큐가 이 프로젝트의 등재를 거절한다.

### 여기서 쓰는 것

| 무엇 | 자리 |
|---|---|
| 코드 검색 · 컨텍스트 문서 | MCP `ax-client` 의 `search_context` — 마스터가 이 레포를 합성한 문서를 찾는다 |
| 편집 중 이웃 문서 힌트 | 훅 `.claude/hooks/domain_hint.py` (`PostToolUse`) |
| 어휘·별칭 | 스킬 `ax-ontology` |

- `ax-client` 는 **로컬 스코프**로 등록돼 있다(`~/.claude.json`) — 이 레포의 `.mcp.json` 은
  사람 것이고 마스터가 건드리지 않는다. 같은 이유로 루트 `CLAUDE.md`·`AGENTS.md` 도 건드리지 않는다.
- 도구 본체는 `.ax/lib/` 에, 프로젝트 태그는 `.ax/config.json` 에 있다. 둘 다 git 밖이다.

### 사실로 알아 둘 것

- 컨텍스트 문서는 이 체크아웃의 Gitea 원격으로 **push 된 커밋**을 기준으로 갱신된다.
  push 전의 로컬 변경은 검색에 나오지 않는다.
- 온톨로지(도메인·별칭) 도구는 마스터가 **마운트한 프로젝트**를 기준으로 답한다. 이 프로젝트가
  마운트돼 있지 않으면 별칭 등록은 `not_mounted` 로 거절된다 — 고장이 아니라 그 상태의 결과다.
- 분산 작업 도구(`register_work` 등)는 이 체크아웃에서 거절된다.
