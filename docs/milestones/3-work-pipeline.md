## 🔴 원전 독파에서 나온 것 (소 3.1.1 ✅ 2026-08-10)

`distributed-workers.md` 426줄을 읽었다. **계획에 없던 칸 넷과 함정 다섯**이 나와 아래가
바뀌었다. 다음 미독분: `README.md` 842 · `watcher-internals.md` 543 · `runbook.md` 280 ·
`extending.md` 251.

🔴 **그대로 이식하면 규약을 깬다**: `generate_skeletons_impl` 은 **마스터가 `repo_path` 에
파일을 직접 쓴다.** 우리는 *"파일은 윈도우를 떠나지 않는다"*(§2)다 → **골조는 텍스트로 낸다.**
원전이 상용 CLI(Gemini) 전제인 것도 다르다 — 우리는 레인 선택이 `synth.CLI_MODELS` 에 있다.

**함정 — 원전이 값을 치르고 배운 것**

- 🔴 **reject 는 폐기·재구현이 아니라 전진·수정이다** (2026-06-21 정정, 사용자 확정). 옛
  구현은 reject 마다 durable 을 골조로 되돌려 **맞게 짠 코드까지 버렸다** → 회귀·비결정성,
  *"이 메서드만 고쳐라"* 식 피드백 무의미. 우리 소 1.3.3 이 그대로 빠질 자리다.
  동반 잠복 버그: *"모든 주석 보존"* 지시가 `[FEEDBACK]` 블록 삭제를 막아 **검증이 무한
  실패**했다 — approve 경로만 본 셀프테스트가 못 봤다.
- 🔴 **워커 1대면 데드락**이었다 — *"verify 우선 + 자기검증 금지"* 가 starvation 을 낳아
  **write 우선 · 자기검증 폴백 허용**으로 뒤집혔다. 우리는 2대지만 **하나가 더티하면 1대**다.
- 🔴 **샌드박스는 거짓 자신감을 준다** — 실 e2e 만이 exe 미번들 · 빌드캐시 staleness ·
  **`.claude/` 가 gitignore 라 매니페스트 커밋이 rc=1 로 실패**하는 것을 드러냈다.
  소 3.1.4(`/cluster-selftest`)의 존재 이유가 이것이다.
- ⚠️ **태그는 두 종류다** — `[PSEUDO]`·`[PSEUDO:N]`·`[IMPL]` 은 워커가 **지우고**,
  `[DOC]`·`[STATE]`·`[BIND]`·`[REPLICATED]` 와 무태그 주석은 **보존**한다. getter/setter 엔
  주석 금지(프롬프트 노이즈). 소 1.1.1 의 실제 계약이고 소 2.1.2 가 검사할 대상이다.
- ⚠️ **Redmine 상태는 이름→id 동적 매핑**이다(환경마다 id 가 다르다). 🔴 우리는 `status_id:4`
  를 하드코딩한다 — 지금은 맞지만 **근거 없이 맞는 중**이다.

**우리가 이미 다르게 풀어 둔 것** (원전을 보고 되돌리지 말 것)

- 원전은 워커가 `reset --hard` + `clean -fd` 전에 **stash** 를 뜬다. 우리는 **더티면 아예
  파견하지 않는다** — 잃을 것을 만들지 않는 쪽이 낫다. stash 경로를 이식할 이유가 없다.
- 원전의 `.h`/`.cpp` 짝 찾기는 **같은 폴더만** 봐서 UE 위젯을 *"헤더 전용"* 으로 오판하고
  **워커 태스크를 통째로 누락**했다(2026-06-07 prod). 우리 stem 방식은 그 50건을 이미 맞힌다.

✅ **반대 방향 버그가 우리에게 있었고 고쳤다 — `.h`/`.cpp` 짝이 아니라 *모듈* 문제였다.**
열쇠가 basename 뿐이라 **다른 모듈의 동명 파일**이 한 단위로 묶였다. 실측 **9건 36파일이
전부 포팅 원본↔대상**(`Project_Alpha/…/Alpha_HexagonTileItem` ↔ `ModularStage/…/동명`)이라,
워커에게 *"이 넷은 한 몸이니 같이 고쳐라"* 가 될 뻔했다 — **원본은 읽기 전용인데도.**
열쇠를 **모듈 + 경로(`Public`/`Private`/`Classes` 제거) + stem** 으로 바꿨다: 850 → **859 단위**,
`.h`/`.cpp` 짝 795건 유지, 모듈 넘는 묶음 0.
