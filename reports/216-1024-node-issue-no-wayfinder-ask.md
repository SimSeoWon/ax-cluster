# 216 — 노드 일감에는 웨이파인더 진행 질문을 붙이지 않는다 (#1024)

> 2026-11-26 · Redmine `#1024` · 마일스톤 8 - 버그/개선 · 분류 버그 · 작업 브랜치 `issue/1024` · 시작 `7fe5a2e`

## 1. 결함

착수 전 인터뷰에서 분류를 「신규 기능」으로 확정하면 `master/interview.py` 가 응답에 웨이파인더 진행 질문
(`wayfinder_ask`)을 붙인다(#982 발동 A — 새 큰 일감을 Root 로 할지). 그런데 **일감 본문을 보지 않고 분류만 봐서**,
이미 지도의 노드인 일감(`<!-- ax:node v=1 root=N type=… -->`)에도 붙었다. 노드는 Root 가 될 수 없어 질문이 쓸모없고,
#741 노드 5개(#1020·#1019·#1022·#1021·#1023)는 이 질문을 피하려고 분류를 「기존 기능 수정」으로 바꿨다(리포트 210 §6·215 §4).

- 원인: #982 T6(`e3cd550`, 2026-11-18) — 노드 제외를 적은 문서는 없었다(규칙이 빠진 것).
- 재현(수정 전 main `7fe5a2e`, 가짜 일감·Redmine 무접촉): 노드 · 깨진 표지 · 일반 **셋 다** `wayfinder_ask` 있음.

## 2. 고친 것

- `interview.record` 가 분류 확정 때 **이미 읽은 본문**을 `map_block.parse_node`(판독 한 벌)로 읽는다.
  - 노드면 질문 생략 + 로그 「노드 일감(Root #R) — 웨이파인더 질문 생략」
  - 표지 접두어는 있는데 형식이 깨졌으면(`MapError`) 생략 + `[주의]` 로그 — 깨진 노드를 Root 로 바꾸는 쪽이 더 위험하다고 봤다
  - 일반 일감은 그대로 묻는다
- 분류 노트 기록은 그대로다 — 바뀐 것은 응답에 질문을 싣느냐뿐이다.

커밋: `c12981a`.
