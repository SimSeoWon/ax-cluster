# 분류: 신규 기능

`#960` 착수 전 인터뷰에서 「신규 기능」으로 확정된 일감의 단계별 안내다. 재현 단계는 이 분류에
적용하지 않는다(머리말 `steps`) — 도구가 건너뜀 노트를 남긴다. 모든 단계는 결과 제시 → 사용자 확인 →
단계 노트로 끝난다.

## 조사 (investigate)

- 참조할 기획서·외부 레퍼런스가 있는가.
- 비슷한 기존 기능이 이미 있는가 — 재료의 RAG·온톨로지 결과에서 찾고 현재 소스로 대조한다.
  있으면 확장할지 새로 만들지가 질문이 된다.
- 사용자에게 확인: 「참조할 기획서가 따로 있나」 · 「이 기존 기능과 같은 것인가, 다른 것인가」.

## 명세 (specify)

- 왜 지금 필요한가, 끝났을 때 누가 무엇을 치고 무엇을 보게 되는가를 사용자 언어로 정한다.
- 이번에 의도적으로 하지 않는 것(비범위)을 반드시 정한다.

## 파급 측정 (impact)

- 새 기능이 붙는 자리의 호출자·인접 모듈·상주 서비스(재기동 필요 여부)·배달 대상.
- 새 표면(MCP 도구·엔드포인트·스킬)이 생기면 요청 태그·권한 범위.
