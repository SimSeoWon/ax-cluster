## 1. 결함

`master/map_block.py` `_marker_span`(→ `parse_node`·`put_node`)은 본문 **전체**에서 노드 표지 접두어를 찾았다.
그래서 사람이 설명하려고 백틱이나 펜스 코드 블록 안에 적은 표지 문자열까지 표지로 셌다 — #982 T2(`744c726`,
2026-11-18)부터. 처음 드러난 것은 #1024 마감(2026-11-26): 본문·스펙이 표지를 인용해 마감 지도 단계가
「노드 표지 2개」로 거절했다(본문 인용에서 주석 괄호를 빼 우회).

판독 한 벌을 다섯 곳이 쓴다 — `interview._node_skip`(#1024) · `wayfinder.on_node_closed`(마감 지도 단계) ·
`wayfinder` 대조(:342) · 노드 생성(:406 `put_node`) · `put_node` 자체.

## 2. 고친 것

- `_mask_quotes(body)` — 인용 구간(펜스 ``` · ~~~, 코드 스팬)을 **같은 길이 공백**으로 가린 사본. 줄바꿈과 위치는
  원문 그대로라, `_marker_span` 은 사본에서 찾고 판독·교체는 원문으로 한다(`put_node` 의 원문 바이트 보존 유지).
  - 펜스: 0~3칸 들여쓴 ``` / ~~~ 3개 이상이 열고, 같은 문자·같거나 긴 줄(뒤에 글 없음)이 닫는다. 안 닫히면 끝까지.
  - 코드 스팬: 펜스 밖에서 같은 길이의 백틱 줄이 닫는다. 짝 없는 백틱은 글자 그대로(→ 그 줄의 표지는 그대로 거절).
- 인용 밖의 깨진 표지(줄 중간·둘 이상·형식)는 지금처럼 `MapError` — #982 의 엄격함(`test_map_block` :229·:235)을 지켰다.
  「한 줄 혼자인 표지만 센다」(방향 B)는 진짜 깨진 줄 중간 표지를 조용히 무시하게 돼 버렸다.
- 다섯 호출부는 손대지 않았다 — 판독 한 벌이 바뀌어 같이 바뀐다.

커밋: `eac2743`(수정 + map_block 재현 검사) · `e2db97e`(호출부 검사).
