## 11. AgentTest 교차 검증 — 된 것 / 안 된 것 (2026-08-08)

> 사용자 지시: **"AgentTest 랑 교차 검증해. 개발된거랑 안된거 정리해"**
>
> 🔴 **이 문서를 만든 이유.** 그동안 조각을 만들고 "완결" 이라 보고하고 다음 조각으로
> 넘어가기를 반복했다. 범위를 만든 것에 맞춰 좁히고, 조사 대신 라벨("2단계", "나중 문제")로
> 처리했다. **분모를 고정하려고 전수 조사한 결과가 이 표다.**
>
> 수치는 전부 실측(`wc -l`, 2026-08-08 저녁). `worker/`(3,657줄)는 작업장 쪽이라 뺐다 —
> 이 문서는 **서버측**만 다룬다.

### 11.7 요약 — 지금 서 있는 위치

**✅ 된 것 (기능 단위)**

- 태스크 큐 · 추론 브로커 · 프로젝트 레지스트리 — 서비스 3종 가동
- 층2 판정(상용 모델) · 층3 게이트(UE5 빌드/테스트) — fail-closed
- 컨텍스트 MD **검색**(벡터+BM25+RRF, 961건)
- 작업 루프: 등록 → 매니페스트 → 생성 → 층2 → 인계
- 이벤트 구동 색인(Gitea 훅 → 스풀 → inotify) — 폴링 대체
- 인증 · 더티 체크 · 2-tier 브랜치 · 노드 프로비저닝

**❌ 안 된 것 (큰 것부터)**

1. **온톨로지 합성** 7,173 — 트윈을 갱신할 수 없다
2. **스킬/에이전트 정의** 3,252 — 손도 안 댔다
3. **온톨로지 관리·조회** 4,832 — 데이터를 읽거나 고칠 수단이 없다
4. **클래스 그래프** 1,341 — 도메인 자동 추론이 죽어 있다
5. **컨텍스트 MD 합성** 1,036 — 새 코드에 문서가 안 생긴다
6. **감사** 1,416 · **웹 UI** 892 · **도메인 색인** 829 · **e2e 자기검증** 416
7. 리뷰·최종 통합 623 · MCP 서버 본체 876 · TDD 드라이런 459
8. redmine · log/crash analyzer · code_recipes · commandlet_runner (2,935)

🔴 **가장 중요한 사실**: 트윈을 **쓰는** 쪽(검색)은 부분적으로 있지만, **만드는** 쪽
(합성 8,209줄 + 클래스 그래프 1,341줄)은 **0** 이다. 지금 트윈은 받아온 스냅샷이고
스스로 자라지 못한다. 워크플로우가 코드를 새로 짜도 그 코드는 트윈에 들어가지 않는다.
