# ax-ontology — 트윈의 어휘를 사람과 함께 정한다

> 마스터가 생성해 배달한다. **손으로 고치지 말 것** — 다음 배달에 덮인다.

## 0. 🔴 온톨로지는 자동이 아니다

마일스톤 목표 ①이 못박고 있다 — 온톨로지는 *"사용자의 수동 명령과 대화형으로 휴리스틱이
포함된"* 것이다. **자동 승급은 오동작 이력으로 폐기됐다**(2026-08-09 사용자 확정, 원본도
2026-06-01 에 영구 비활성).

그래서 이 스킬의 규칙은 하나다: **제안하고 묻는다. 자동으로 넣지 않는다.**

## 1. 왜 이게 필요한가 — 실측된 공백

BM25 토크나이저는 `[A-Za-z0-9_]+|[가-힣]+` 리터럴 매칭이라 **「몬스터」와 `AMonster` 가
영원히 안 만난다.** 그리고 실측(2026-08-09):

    질의 「미션 태스크 실행」 →  MissionEditor 0.4883 / MissionRuntime 0.4778 (2% 차)

`MissionRuntime` 이 「미션」8회·「실행」6회로 **더 많이 갖고도 졌다.** 원인은
**tags 채널(가중치 3.0)에 한글이 0개**라 한글 질의에서 최고 가중치 채널이 통째로 안 걸린 것.
반면 `MissionSystemTools` 는 본문에 「태스크」가 **0회**인데 **한글 태그 4개만으로** 상위권이었다.

🔴 **받아온 온톨로지 247개 중 `aliases` 보유가 0건이다.** 이 스킬이 그 0을 메운다.

## 2. 용어를 만나면 — 조회하고, 없으면 묻는다

사용자가 `[미션 시스템]` 처럼 **대괄호로 개념을 감싸면** 그게 등록 신호다.

    resolve_terms_tool(terms)     ← 시소러스에 있나? 없으면 **후보를 붙여** 돌려준다

돌아온 것을 그대로 넣지 않는다. **후보를 근거와 함께 사용자에게 보인다:**

> `[미션 시스템]` 은 아직 등록돼 있지 않습니다. 후보가 이렇게 보입니다 —
> `UManager_Mission`(미션 흐름 제어) · `UMissionTaskExecutor`(태스크 순차 실행).
> 어느 것으로 걸까요? 둘 다 아니면 직접 알려 주세요.

**근거 없이 후보만 나열하지 않는다** — 그러면 사용자가 판단할 수 없고 "다 넣어" 로 끝난다.

## 3. 확인받은 것만 등록한다

    add_alias_tool(class_name, term)      ← 🔴 **기존 별칭에 합친다. 덮어쓰지 않는다**
    mark_not_a_class_tool(term)           ← "그건 클래스가 아니다" → 다음부터 안 묻는다

`mark_not_a_class_tool` 을 아끼지 말 것. 「빌드」·「배포」처럼 클래스가 아닌 말이 매번
후보로 올라오면 사용자가 같은 질문에 계속 답해야 한다.

## 4. 검색 입구는 하나다

    search_context_tool(query, limit)

🔴 **이것만 쓴다.** 대괄호 해석 → 시소러스 확장 → 검색을 한 번에 한다. 다른 경로로 돌면
방금 등록한 별칭이 안 걸려 **등록 효과가 없는 것처럼 보인다.**

등록 직후 같은 질의를 다시 돌려 **실제로 좋아졌는지 확인**하고 사용자에게 보여 준다.
안 좋아졌으면 그 사실을 말한다 — 별칭이 만능은 아니다.

## 5. 🔴 지금 이 스킬로 할 수 없는 것

| | 상태 |
|---|---|
| 별칭(시소러스) 등록 | ✅ 된다 (위 도구들) |
| **도메인 생성·경계 편집** | ❌ **마스터 측 도구가 아직 없다** (소 1.3.1 / 1.3.2) |
| 도메인 MD 의 한글 태그 등록 | ❌ 아직. 🔴 **선결이 하나 더 있다** — 합성기가 MD 태그를 `domain.yaml` 로 전파하지 않는다(실측 2026-08-09) |

**없는 것을 있는 척하지 않는다.** 사용자가 도메인 경계를 고치고 싶어 하면, **지금은 마스터에서
직접 해야 한다**고 말하고 레드마인 #23 을 가리킨다.

## 6. 판단 기준

🔴 **소스가 이긴다.** 별칭을 걸 클래스가 실제로 존재하는지, 이름 철자가 맞는지는
**선언부를 열어 확인**한다 — 없는 클래스에 별칭을 걸면 검색이 **틀린 자리로 보낸다.**
그건 이 프로젝트에서 가장 나쁜 실패다: 문서는 지도인데 틀린 지도가 된다.
