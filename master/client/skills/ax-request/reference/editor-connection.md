# 0.06 [중요] **에디터를 건드리는 요청이면 연결부터 확인한다** (`#374`)

> `ax-request` SKILL.md 에서 옮긴 본문이다(`#890` T5 — 내용은 그대로, 제목 단계만 올렸다).


훅이 **이상할 때만** 한 줄을 낸다 — `꺼짐` · `🔴 이 세션은 못 붙었다` · `에디터가 꺼졌다` ·
`MCP 응답이 아니다`. [중요] **줄이 없으면 붙어 있는 것이다**(사용자 결정 2026-09-06: 정상은
조용하다). 실측 2026-09-05: 한참 작업한 뒤에야 *"세션 시작할 때부터 unreal-mcp 연결이 실패한
상태였다"* 를 알았고, 그래서 사람에게 IMC 설정 확인을 부탁하게 됐다.

    필요 없다   소스 코드 작성·빌드·로그 분석 — 대부분의 요청이 여기다. **그냥 진행한다**
    필요하다    블루프린트 그래프 · IMC/Input Action 애셋 · 머티리얼 · 레벨 배치 ·
                에디터 자동화 테스트 — 즉 `mcp__unreal-mcp__*` 를 쓸 일

🔴 [중요] **판정은 네가 한다 — 훅은 문장에서 애셋 여부를 가르지 않는다.** 요청이 위 오른쪽
칸에 걸리는데 고지가 「꺼짐」이나 「못 붙었다」였으면, **작업을 시작하기 전에** 사람에게
말한다:

> "이 요청은 에디터(블루프린트/애셋)를 건드려야 하는데 지금 세션은 `unreal-mcp` 에 붙어
> 있지 않습니다. **에디터를 켜 주시고**, 켜지면 **`/mcp reconnect unreal-mcp` 를 실행해**
> 주시겠어요? (세션을 새로 열 필요는 없습니다.)"

🔴 [중요] **그 명령은 사람이 친다 — 내가 실행할 수 없다.** 슬래시 명령은 세션의 도구가 아니다.
사람이 자리에 있으니 **대신 부탁하는 것**이 이 자리의 행동이다 (사용자 지시 2026-09-06).
이 프로젝트의 규약과도 같은 방향이다 — *"사용자가 세션에 있는 동안 추측을 적립하지 않는다,
대화로 묻는다"*.

🔴 [중요] **재연결이 필요한 경우는 하나뿐이다 — 「세션 시작에 서버가 없었을 때」** (실측
2026-09-06, 가짜 MCP 서버로 6회):

    세션 시작에 붙어 있었다  3초 중단 ✅ · **75초 중단 ✅**  → 리빌드는 **사람이 할 일이 없다**
    세션 시작에 없었다      2초 ✅ · **10 · 20 · 55 · 170초 ❌ 도구없음** → `/mcp reconnect` 필요

[주의] **종전 서술 「세션 시작에 한 번만 붙고 자동 재시도가 없다」는 폐기됐다.** 원전 런북
§12-5 를 지금 도구로 재보지 않고 옮긴 것이 출처였다.
그래서 **리빌드(`에디터 종료 → 빌드 → 기동`)는 그냥 다시 켜 달라고만** 하면 된다. 반대로
훅이 `🔴 이 세션은 못 붙었다` 를 냈으면 켜는 것으로는 안 되고 **`/mcp reconnect` 요청**이다.
세션 재시작은 그것도 안 될 때의 차선이다 — 맥락을 버리는 값이 크다.

[중요] **에디터를 대신 켜지 않는다** — 사람의 기계이고, 켜는 것은 사람의 결정이다.
[중요] **꺼져 있다고 요청을 거절하지 않는다** — 소스 쪽 작업은 그대로 하고, 에디터가 필요한
조각만 남겨 알린다.
[주의] 지금 서버 상태를 다시 재려면 `py .claude/hooks/editor_mcp.py`. 그것은 **서버**가 살아
있는지만 말한다 — 이 세션이 붙었는지의 결정적 확인은 `mcp__unreal-mcp__*` 도구가 이 세션의
도구 목록에 있는지다.
